# Geometric Algebra Learning Physics Engine

Welcome to the documentation for the Geometric Algebra Learning Physics Engine!

This project is a physics engine designed primarily as an educational tool for learning Geometric Algebra (GA) and its applications in physics simulation. By building a physics engine from the ground up using GA instead of traditional vector algebra and matrices/quaternions, learners can gain an intuitive understanding of multivectors, wedge products, rotors, and other core GA concepts.

## Goals

1. **Teach Geometric Algebra (GA):** Provide an interactive playground to learn about GA and see it applied practically.
2. **Physics Simulation:** Implement core physics engine components (kinematics, rigid body dynamics, collision detection) using pure Geometric Algebra.
3. **Clarity over Optimization:** The code is written to be readable and instructional, prioritizing clarity over aggressive optimization.

## Quick Start

### Installation

Clone the repository and explore the documentation to learn more about how GA is used in this physics engine.

```bash
cd ga-physics-engine
```
